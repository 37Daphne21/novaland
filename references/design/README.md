# Nova Land Design References

이 폴더의 이미지는 Nova Land 구현을 디벨롭할 때 사용하는 비주얼·구조 참고 자료다.

확정 시안이 아니므로 `project.md`, `roadmap.md`, 최신 구현과 충돌하면 그대로 복제하지 않는다. 이미지의 공간감, 정보 계층, 시설별 분위기와 공통 UI 원칙을 참고하되 현재 확정된 Flow와 Component 구조를 우선한다.

---

## NOVA COASTER Control Room

- `pc_novaland_controlroom_coaster.png`
- `pc_novaland_controlroom_coaster2.png`

시설 내부 관제실의 공간감, 중앙 열차와 Rail Network Console, EVE·Mission Objective·Train Status 배치를 참고한다. 세부 문구, 수치와 Mission 규칙은 확정값으로 사용하지 않는다.
