# LUNA 관제실 배경

v1은 승인된 원본으로 보존한다. 넓은 천장·바닥과 축소된 풍경의 v2는 폐기했다. v3는 비교용 미사용 자산이며 현재 웹에는 원본 v1을 적용한다. 테이블 깊이를 유지하고 시작 버튼 크기를 조정하는 방향으로 결정했다.

## v3 생성 지시

내장 image_gen 사용. v1의 카메라·온실 크기·달빛·금빛 재질과 밝기를 유지하고 큰 식물 홀로그램 구체를 원래 왼쪽 위치와 크기로 유지한다. 중앙 테이블의 앞뒤 깊이만 줄여 이미지 높이 70~80%에 들어오게 하고 아래에 기존 석재 바닥을 자연스럽게 잇는다. 방 전체를 축소하거나 천장 여백을 확대하지 않는다. UI·문자 없이 16:9 배경으로 생성한다.
